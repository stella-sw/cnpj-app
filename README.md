# CNPJ Data App

Aplicação para ingestão e visualização de dados públicos do CNPJ utilizando DuckDB e Streamlit.

---

## Funcionalidades

- Busca por razão social
- Busca por CNPJ
- Filtro por UF
- Visualização de dados cadastrais
- Estrutura para estabelecimentos e sócios

---

## Tecnologias

- Python
- DuckDB
- Streamlit
- Pandas
